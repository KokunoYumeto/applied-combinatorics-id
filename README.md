- `02_KOMBINATORIKA_TERAPAN_ID-ID_EVIDENCE_AND_PROVENANCE_2026.08.22.2.zip` — identitas sumber, backend modular, terminologi, koreksi, QA, bukti bangun, dan provenance.

Backend modular memuat ID unit dan segmen stabil, urutan/hierarki, konsep dan prasyarat, terminologi, relasi latihan–solusi, aset, hak komponen, koreksi, peristiwa QA/bangun, serta manifes artefak dalam JSON/JSONL/CSV deterministik.

Hak cipta karya sumber tetap pada Mitchel T. Keller dan William T. Trotter. Rilis pemeliharaan ini mencatat QA terminologi lapangan Bahasa Indonesia, menyeragamkan 35 pemakaian `verteks` menjadi `simpul`, menambah varian glosarium yang terverifikasi, dan menambahkan provenance model; struktur matematika, rumus, ID, referensi silang, latihan, lisensi, dan otoritas hulu tetap dipertahankan. Edisi ini tidak didukung atau disahkan oleh para penulis sumber. Terjemahan, pelokalan, backend, dan metadata dibantu oleh OpenAI Codex gpt-5.6-sol, Ultra. Pekerjaan dilakukan atas permintaan pengguna.
